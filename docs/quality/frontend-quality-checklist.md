# Checklist de calidad frontend CPA

- [x] TypeScript estricto.
- [x] Build productivo validado.
- [x] Pruebas unitarias con Jest.
- [x] Reglas contables aisladas en modelo puro.
- [x] Hooks usados como ViewModels.
- [x] Componentes visuales con responsabilidad única.
- [x] Borradores backend encapsulados en servicio/hook.
- [x] Normalizadores defensivos testeados.
- [x] Sin dependencia de mocks para perfil o sesión.
- [x] No se crean transacciones manuales en flujo venta-clase.
